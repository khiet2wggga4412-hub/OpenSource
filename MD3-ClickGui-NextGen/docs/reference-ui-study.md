# Athena UI 逐帧研究与实现记录

参考视频：`SVID_20260924_205532_1..mp4`。研究日期：2026-09-24。

本次按视频的真实帧时间戳研究布局、控件和动画，并将可确认的规律用于现有 Compose 界面。用户此前明确指定的连续滑动色块、无水波纹、左侧文字渐显渐隐、移除右侧模块启用开关继续优先适用。用户随后要求降低点击响应延迟，明确保持动画时长不变。因此点击事件立即更新状态，动画独立播放，不以缩短动画代替响应优化。

## 布局与层级

以约 4.997 秒的稳定画面为主要布局样本：外层面板约 980×610 原始像素，三栏约为 160 / 280 / 500 像素，余量用于内边距和栏间隔。视频后半出现界面缩放设置，因此不直接将“占屏宽约一半”套用为本项目的默认窗口大小。

| 部分 | 视频可见规律 | 本项目实现 |
|---|---|---|
| 分类栏 | 窄行、图标左侧固定，名称及数量同一行；Settings 位于底部 | 40dp 行高，图标 20dp；Config 底部固定；展开 164dp、收起 56dp |
| 模块栏标题 | 分类和 Modules 为双行，Search 同行靠右 | 搜索与标题共用 48dp 的一行，显示实际模块数量 |
| 模块列表 | 名称上、所属分类下，右侧紧凑开关，行间隔约 5px | 最小行高 56dp、间隔 4dp，移除多余模块图标；只在此处保留模块启用开关 |
| 详情标题 | 模块名、分类、Floating Button 独立分层 | 标题与悬浮按钮选择分两行；右上保留关闭按钮 |
| 开关/选择行 | 约 54px 高，标题与控件垂直居中 | 最小行高 48dp，名称和控件列约 35% / 65% |
| 滑杆行 | 约 64–66px 高，比开关行更宽松；数值右对齐 | 最小行高 56dp，轨道 8dp、细竖滑块 4×24dp，行尾数值宽 56dp |
| 配色 | 深色中性底，紫色强调选中状态；层级主要由表面色区分 | 保留可配置主题体系，通过一致尺寸、层级与间距对齐参考；未强制覆盖用户主题 |

中间模块列按照展开时的可用宽度确定；侧栏收起时主要把空间让给详情，模块列宽保持稳定。很窄的窗口仍受可用宽度限制，分类标签在工作区小于 720dp 时自动隐藏。

仅展示已实现的 Scaffold、Theme、Language 模块，不为仿照参考列表密度添加无功能条目或虚构数量。

| 动作与证据 | 观察结果 | 实现参数与取舍 |
|---|---|---|
| 详情切换，f125–165，1.173–1.645s | f125 旧内容完整，f126 已基本消失；新内容约 450ms 渐显。首次切换有约 10 原始像素的横向偏移 | 旧内容 90ms 淡出，新内容 450ms 渐显并移动 8dp；点击事件立即更新详情目标 |
| [选中行交接](../artifacts/reference-study/selection_first_switch.jpg)，另见 16.41–16.70s | 旧行与新行固定位置颜色交接，更接近淡入淡出 | 用户明确要求滑动，采用一个父容器选中背景，240ms 跨行连续移动，包含行间空隙 |
| [下拉展开](../artifacts/reference-study/middle_menu_open_00.jpg)，8.98–9.29s | 从锚点下缘向下显露并渐显，不挤动后续设置 | 300ms 展开与渐显；空间不足时改向上展开 |
| [下拉收起](../artifacts/reference-study/middle_menu_close_00.jpg)，9.40–9.65s | 高度向锚点收回、透明度下降 | 选项点击立即提交；240ms 收起和淡出，动画结束后仅卸载弹层 |
| [滑杆拖动](../artifacts/reference-study/middle_slider_00.jpg)，约 9.98–10.30s | 填充轨道、细竖滑块、行尾数值同步；气泡跟随滑块 | 采用同一交互源驱动 Slider 与数值 Label，松手后关闭气泡 |
| [侧栏收起](../artifacts/reference-study/middle_rail_collapse_00.jpg)，12.83–13.06s | 图标保持锚定；文字渐隐；中间列整体左移，宽度基本不变 | 宽度 220ms；文字收起 100ms、展开 160ms，不增加启动延迟；文字不伸缩和换行 |
| 再次收起，f1872–1893，20.824–21.042s | 半尺寸帧中模块背景左边由 x≈319 移到 x≈264，宽度约 137px 不变 | 佐证约 190–220ms 的主要宽度过渡，以及中间列保持宽度的布局策略 |
| 窗口关闭，21.85–22.24s、23.23–23.61s | 整窗下移、略微缩小并渐隐，悬浮入口显现 | 400ms，缩放至 0.97，向下移动约面板高度的 16% |
| 窗口打开，22.70–23.12s、23.88–24.35s | 从较低位置回到稳定位置，渐显；约 400–450ms | 关闭动作的逆过程；入口、快捷浮钮使用相同 400ms 时间级别 |

关闭测量补充：f1964 的开关中心约为 (695.8, 317.4)，f1975 约为 (694.2, 354.8)，均为半尺寸帧坐标。可见约 75 原始像素的向下移动，后段透明度过低使测量混入背景。窗口总位移和 0.97 缩放是视觉近似值，不是从源码得到的精确参数。

主要缓动使用 `CubicBezierEasing(0.2, 0, 0, 1)`，集中于 `NexusMotion.kt`。这是匹配先快后慢观感的实现选择；视频不能唯一确定贝塞尔控制点。

## 控件行为

Floating Button 采用 Off / On 分段，选中底色水平滑动。语言选择也使用两段控件。其他多项选择使用有展开/收起过程的锚定菜单，支持返回键、点外部关闭和键盘方向键选择。

扩展长度使用 1–6 格的离散滑杆，含 4 个内部刻度。状态层同时限制范围并对齐步长，兼容旧配置中的非整数值。计时速度保持连续调整，显示两位小数。

开关保留 40×24dp 可见轨道与 48dp 点击区域，开启时滑块略增大；控件运动为 160ms。所有自定义点击区域显式关闭 indication，Material 组件通过主题禁用水波纹。

颜色选择器未在本视频中展示，不能声称其内部布局来自参考。现有选择器继续使用，横屏中限制色板大小并支持滚动；应用颜色时先等待抽屉的关闭动画结束，再移除组件。

响应路径改动：分类点击直接更新所选模块，避免依赖下一次组合后的副作用更新详情；下拉选择立即提交，移除等待 240ms 关闭动画的逻辑；关闭中的弹层及时释放焦点，并可反向重新打开。左侧文字取消 60ms 启动等待，渐显本身的时长保持 160ms。这些是可确认的代码路径改动，不等同于已测得所有设备上的触屏到显示端到端延迟。

搜索只观察到获得焦点与系统键盘出现，没有足够输入证据推断参考的过滤规则。本项目继续按原始名称与翻译名称搜索。
